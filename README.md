# H5 Tools

一组轻量的 H5 工具集合。所有数据保存在本地浏览器（`localStorage` / `IndexedDB`），无需后端、无需登录，打开即用。

## 内含工具

| 入口 | 名称 | 说明 |
| --- | --- | --- |
| `index.html` | 每日喝水 | 记录每日饮水量，统计图表可视化 |
| `checkIn.html` | 打卡助手 | 上下班打卡、累计在班时长、月度汇总，支持数据导入/导出 |
| `feishu.html` | 通往 AGI 之路 | AI/Agent/Skill/Codex 等文章分类索引 |
| `list/index.html` | 任务管理 | 静态资源可直接运行。源码暂未开源 |
| `whereismoney/index.html` | 宝盒是怎样月光的 | 记录月收入、分期与支出，预测未来 36 个月还剩多少现金可用，提前看见月光红线 |

> 每个入口都是一个独立的静态页面，下载或部署后用浏览器打开对应的 HTML 即可使用。

## 使用

直接双击或在浏览器中打开 `index.html` 即可使用每日喝水。

打卡助手、AGI 文章索引同理。

任务管理见 `list/index.html`，宝盒是怎样月光的见 `whereismoney/index.html`。

## 数据与隐私

- 所有数据仅存储在当前浏览器的本地存储中
- 不向任何远端服务发送数据
- 切换浏览器或清除浏览数据会导致记录丢失，请使用工具自带的「复制数据 / 合并数据」功能做备份
